# SwerveNServe-Loop

A Crazy Taxi-style courier game on foot, set in a compact, hand-authored slice of a fictional city at night — rendered with an early-PS2-inspired look (low-poly characters, pixelated photo-textures, heavy fog, saturated artificial lighting).

**Platform:** Desktop web browser
**Engine:** Three.js
**Language:** TypeScript
**Build tooling:** Vite

## Core loop

Pick up a job → choose a route → deliver → earn cash/score → take the next job, against a countdown timer. The fun comes from learning the neighborhood: recognizing shortcuts, deciding whether a risky route is worth it, recovering from mistakes, and holding a delivery streak under time pressure.

## Demo scope

One replayable 10–15 minute night in one compact neighborhood (roughly three dense, interconnected blocks): a fast but exposed main avenue, a tight rowhouse/alley maze with shortcuts, and a quieter residential/vacant-lot edge. Includes a countdown timer, pickup/drop-off markers, semi-randomized routes, cash/score rewards, an end-of-run results screen, and instant restart.

Combat, Heat/pursuit, and online leaderboards are stretch goals — never required for the core loop.
